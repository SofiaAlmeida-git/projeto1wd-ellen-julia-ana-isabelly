# 🌷 Florentia Flowers

**Flores que transformam momentos em lembranças!**

A Florentia Flowers é um projeto de loja virtual desenvolvido para apresentar e comercializar flores e produtos artesanais feitos com hastes de chenille. O site oferece uma experiência de navegação intuitiva, permitindo que os clientes explorem produtos, personalizem buquês e simulem suas compras de maneira simples e agradável.

## 🌸 Sobre o projeto

O projeto foi desenvolvido com o objetivo de criar uma loja virtual moderna e responsiva, valorizando a identidade visual da Florentia Flowers e proporcionando uma experiência de compra agradável aos usuários.

A identidade visual utiliza uma combinação de verde, rosa e tons de creme, transmitindo delicadeza, criatividade e elegância.

## Funcionalidades

- **Página inicial:** apresentação da loja e produtos populares.
- **Catálogo de produtos:** visualização dos produtos disponíveis.
- **Filtros de pesquisa:** busca por categorias, cores e preços.
- **Detalhes dos produtos:** informações, preços e opções de cores.
- **Personalização de buquês:** escolha de flores, cores e quantidades.
- **Carrinho de compras:** adição e remoção de produtos.
- **Finalização de pedidos:** formulário com dados de entrega e opções de pagamento.
- **Sobre a loja:** apresentação da história da Florentia.
- **Página de contato:** informações para comunicação com a loja.
- **Modo escuro:** opção para alternar entre temas claro e escuro.
- **Design responsivo:** adaptação para computadores, tablets e celulares.

## Tecnologias utilizadas

- **HTML5:** estruturação das páginas.
- **CSS3:** estilização, identidade visual e responsividade.
- **JavaScript:** funcionalidades, interações e manipulação do carrinho.

## Identidade visual

A interface foi desenvolvida com uma paleta de cores delicada:

- 🌿 Verde: natureza e tranquilidade.
- 🌸 Rosa: delicadeza e romantismo.
- 🤍 Creme: leveza e elegância.

## Como executar o projeto

1. Faça o download ou clone este repositório:

   ```bash
   git clone URL_DO_REPOSITORIO
   ```

2. Entre na pasta do projeto.

3. Abra o arquivo `index.html` no navegador.

Não é necessário instalar dependências ou configurar um servidor para visualizar a versão atual do projeto.
